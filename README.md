# FinTrack — Income & Expense Tracker

FinTrack is a web-based income and expense tracking application that helps users record transactions, monitor their finances, and view a summary of their income and expenses through an interactive dashboard.

**Live Demo:** [Try FinTrack](https://income-expense-tracker-webapp.netlify.app)

## Features

- **Financial Summary Dashboard** — View total income, total expenses, and current balance at a glance.
- **Transaction Management** — Add new financial transactions and edit or delete existing records.
- **Transaction History** — View recorded transactions in an organized table.
- **Search Transactions** — Search through transaction records to find specific entries.
- **Transaction Filtering** — Filter the transaction history by income or expense type.
- **Interactive Charts** — Visualize income versus expenses with a bar chart and explore expense categories with a doughnut chart.
- **Data Persistence** — Keep transaction records available after refreshing the page.
- **Responsive Interface** — Use the application on desktop and mobile screens.

## How to Use

1. Open FinTrack in your browser.
2. Add an income or expense transaction.
3. Enter the relevant transaction details.
4. View your updated income, expense, and balance summaries.
5. Browse your transaction history.
6. Search for transactions or filter the history by income or expense.
7. Edit or delete a transaction when necessary.
8. Use the charts to understand your financial records.
